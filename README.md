# site-web
Кубик & Co

Сайт антикафе «Кубик & Co» — место для настольных игр, бронирования столов и проведения ивентов.

ОПИСАНИЕ

Проект представляет собой многостраничный статический сайт, свёрстанный на HTML5, CSS3 и чистом JavaScript. Сайт состоит из трёх основных страниц:

- О нас (page1.html) — информация об антикафе, слайдер с ближайшими ивентами.
- Игры (page2.html) — карточки игр с возможностью оставить заявку через модальные окна.
- Бронирование (page3.html) — форма бронирования стола с валидацией полей.

ТЕХНОЛОГИИ

- HTML5
- CSS3 (Flexbox, Grid, медиазапросы)
- JavaScript (ES6)
- Bootstrap 5 (только для страницы бронирования, подключён через CDN)

УСТАНОВКА И ЗАПУСК

1. Скачайте все файлы проекта в одну папку.
2. Убедитесь, что рядом с HTML-файлами находятся папки:
   - images/ — все изображения (логотипы, картинки игр, фоны).
   - fonts/ — файлы шрифта 5ka-sans-design.woff2 и 5ka-sans-design.woff.
3. Откройте page1.html в любом современном браузере.

ВАЖНО: ШРИФТЫ

Если у вас нет файлов шрифтов, браузер выдаст ошибку ERR_FILE_NOT_FOUND в консоли. Чтобы этого избежать:

- либо положите шрифты в папку fonts/,
- либо удалите блок @font-face из всех CSS-файлов (тогда будет использоваться системный шрифт sans-serif).

BOOTSTRAP

Страница page3.html использует Bootstrap 5 через CDN. При открытии файла локально браузер может блокировать доступ к внешнему хранилищу (предупреждение Tracking Prevention). Это не влияет на работу сайта. Если хотите избавиться от предупреждения, скачайте bootstrap.min.css и подключите его локально.

ФУНКЦИОНАЛЬНОСТЬ

Главная страница (page1.html)

- Адаптивная шапка с навигацией.
- Слайдер с ближайшими ивентами (переключение стрелками, точками, клавишами ←/→).
- Блок с информацией об антикафе.
- Кнопка «Узнать!» (можно добавить ссылку).

Страница игр (page2.html)

- Три карточки с играми.
- Кнопка «Оставить заявку» открывает модальное окно с выбором кубиков.
- Далее — форма с именем и телефоном.
- После успешной отправки появляется уведомление «Заявка успешно отправлена!».

Страница бронирования (page3.html)

- Форма с полями: день, количество гостей, имя, телефон.
- Проверка на заполненность всех полей.
- При успехе — всплывающее уведомление.
- Используется Bootstrap для сетки.

ОСОБЕННОСТИ РЕАЛИЗАЦИИ

- Все стили разбиты по страницам для удобства поддержки.
- JavaScript-код не использует сторонних библиотек, кроме Bootstrap на одной странице.
- Модальные окна и уведомления закрываются по клику на фон или по кнопке закрытия.
- Валидация форм реализована на чистом JS.

ИЗВЕСТНЫЕ ПРОБЛЕМЫ

1. Отсутствие файлов шрифтов — приводит к ошибкам в консоли. Решение: добавить шрифты или удалить @font-face.
2. Предупреждение Tracking Prevention — возникает из-за подключения Bootstrap через CDN. Не влияет на работу.
3. Кнопки без type="button" — рекомендуется добавить для предотвращения неожиданной отправки форм (если кнопка окажется внутри формы).
